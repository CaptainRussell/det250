Set up Cadre Admin

Do this once. Storm HQ is stored on GitHub, so the admin page needs a GitHub access key that can change the site. You lock that key behind an admin password, and cadre then sign in with only the password.

  1. Sign in to GitHub with the account that owns the site, then open New fine-grained token.
  2. Name it Storm HQ admin, set an expiration (up to 1 year), and under Repository access pick Only select repositories and the Storm HQ repository.
  3. Under Permissions, set Contents to Read and write. Nothing else is needed.
  4. Generate the token, copy it and paste it below.

At least 10 characters. Share it only with cadre who maintain Storm HQ.
