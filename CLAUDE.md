## Who and what
- Owner: Captain Scott D. Russell, USAF. Operations Flight Commander, AFROTC Detachment 250, Iowa State University (office symbol AFROTC DET 250/OFC). Call him Captain Russell.

## Adding a tool
1. Put it in its own folder with `index.html`. Use relative paths only.
2. Add the shared bar: `<link rel="stylesheet" href="../shared/det250.css">` in `<head>`, and copy the `<a class="d250-bar" ...>` line from the top of `org-chart/index.html` to just after `<body>`.
3. Add the standard tool header (`<header class="d250-head inbar" style="--tone:...">`, plus the `d250-tool` name in the bar; see Shared design) and footer (`<footer class="d250-foot">`). Markup for both is in the comments in `shared/det250.css`; copy from `org-chart/index.html`. Use the tool's hub card `tone`, and the `--d250-*` tokens for colors.
4. Add one entry to `data/hub.js`.
5. Cite regulations and forms with `D250Refs` from `shared/doc-refs.js` (see the table above), not with a tool's own document list.
6. Avoid localStorage key collisions (all tools share one origin). Existing keys: `det250-wing-memory-v1` (Know Your Wing), `gmc-strat-v3` (Flight Staff Evaluation, old key name kept so saved work carries over), `d250-gmc-pass` (sessionStorage, GMC unlock), `d250-class-roster-v1` (shared class roster), `d250-class-name-v1` (shared class or course name, set in the "Class" box on each instructor tool), `d250-spin-wheel-v1`, `d250-make-the-call-v1`, `d250-battle-buddy-v1`, `d250-practicum-settings-v1`, `d250-ribbon-rack-v1`, `d250-docs-pass` (sessionStorage, Documents and Policy and ODT Tool unlock), `d250-docs-sections-v1` (collapsed categories), `d250-docs-back-<tool>` (sessionStorage, viewer back link), `d250-peer-feedback-v1`, `d250-peer-code` (sessionStorage), `d250-cadre-pass` (sessionStorage), `d250-cadre-ui-v1`, `d250-admin-pass` (sessionStorage), `d250-admin-ui-v1`, `d250-role` (sessionStorage, hub sign-in role), `d250-signin-v1` (Keep me signed in), `d250-pfra-progress-v1` (sessionStorage, PFRA Calculator inputs kept across a trip to a reference), `d250-odt-me-v1` (ODT Tool: the cadet picked in Find your room and van), and Practicum Adventure's own `sq_*` keys.
7. Instructor tools use the standard screen from `shared/instructor.js`: Class box + step tabs in the header, step 1 Roster (roster panel left, tool setup right), a Next button at the bottom right of each step, tool controls on the right of each step heading.
