## Adding a tool
1. Put it in its own folder with `index.html`. Use relative paths only.
2. Add the shared bar: `<link rel="stylesheet" href="../shared/det250.css">` in `<head>`, and copy the `<a class="d250-bar" ...>` line from the top of `org-chart/index.html` to just after `<body>`.
3. Add the standard tool header (`<header class="d250-head" style="--tone:...">`) and footer (`<footer class="d250-foot">`). Markup for both is in the comments in `shared/det250.css`; copy from `org-chart/index.html`. Use the tool's hub card `tone`, and the `--d250-*` tokens for colors.
4. Add one entry to `data/hub.js`.
5. Cite regulations and forms with `D250Refs` from `shared/doc-refs.js` (see the table above), not with a tool's own document list.
6. Avoid localStorage key collisions (all tools share one origin). Existing keys: `det250-wing-memory-v1` (Know Your Wing), `gmc-strat-v3` (Flight Staff Evaluation, old key name kept so saved work carries over), `d250-gmc-pass` (sessionStorage, GMC unlock), `d250-class-roster-v1` (shared class roster), `d250-class-name-v1` (shared class or course name, set in the "Class" box on each instructor tool), `d250-spin-wheel-v1`, `d250-make-the-call-v1`, `d250-battle-buddy-v1`, `d250-practicum-settings-v1`, `d250-ribbon-rack-v1`, `d250-docs-pass` (sessionStorage, Documents and Policy and ODT Module unlock), `d250-docs-sections-v1` (collapsed categories), `d250-docs-back-<tool>` (sessionStorage, viewer back link), `d250-peer-feedback-v1`, `d250-peer-code` (sessionStorage), `d250-cadre-pass` (sessionStorage), `d250-cadre-ui-v1`, `d250-admin-pass` (sessionStorage), `d250-admin-ui-v1`, and Practicum Adventure's own `sq_*` keys.
7. Instructor tools use the standard screen from `shared/instructor.js`: Class box + step tabs in the header, step 1 Roster (roster panel left, tool setup right), a Next button at the bottom right of each step, tool controls on the right of each step heading. Rosters start empty; the only built-in names are the optional org chart preset groups in `shared/cadet-groups.js` (added Oct 2026 at Captain Russell's request).

## Org Chart details (`org-chart/index.html`)
All data is in `data/roster.js` (`D250_ROSTER`); the page reads it into the same names:
- `PEOPLE` (`people`): photo key -> [last, first, class]. Photo file is `photos/<key>.jpg` (key = name with non-letters removed, for example `ReidElijahB`). Missing photos show initials.
- `SEATS` (`seats`): one row per POC-chart position: `id, des, title, poc:[key, rank], flip (key), parent, dir`, optional `flipDes`, `flipTitle`, `pocDes`. A seat without `flip` is hidden during Flip Week. Cadre seats use `cadre:true` and also have office symbols in `des`.
- `position-descriptions.js` stores position-based OPLAN critical roles and full responsibility bullets, plus cited cadre summaries from the supplied Vol 2 and Vol 3, primary/alternate duties from the signed 27 July 2026 duty memo, and Capt Russell’s clarification of the secretary’s ISU liaison role. The detail drawer uses shared squadron/flight descriptions in both views. The seven GMC deputy seats without separate OPLAN descriptions use supporting duties based on Capt Russell’s local guidance and their supervisor’s OPLAN scope; responsibility remains with the supervisor. The Flip Week GMCIC role still has an explicit source-gap note. Keep source paragraph/page citations with duty updates.
- `FLIGHTS` (`flights`, GMC per flight) and `FLIGHTS_POC` (`flightsPoc`, POC per flight), keyed `afl`, `bfl`, `cfl`, `dfl`. Flight member seats are generated from `FLIGHTS`.
- Views: POC Chart (default), Flip Week (`?view=flip`) and Proposed 2027 Org Charts (`?view=proposed&proposal=<team id>`, teams in `proposals.js`). Deep link to a seat with `#<seat id>`. The tool header (name, description) scrolls away; below it a thin sticky chart bar (`nav.chartbar`) holds the chart picker and, when the proposed charts are open, the team picker (`#team-tabs`) on the same bar (Captain Russell, 13 Nov 2026). `org-chart/index.html`, `proposals.js` and `proposals.css` use CRLF line endings; keep them.
- Ranks during Flip Week are automatic: AS100 = C/4C, AS200/AS250/AS500 = C/3C.
- AS colors (`RINGS`): AS100 blue, AS200 purple, AS250 teal, AS300 green, AS400 orange, AS500 red, Graybeard (AS700/AS800) navy, Cadre slate.
- No class-color legend row, no "Showing the ... chart" line, and no "Chart" row in the details pane (removed Oct 2026).
- Features: Cadre section collapsed by default; Wing Command Team, A-Staff Directorates, Group Staff; "View flight" window per FLT/CC with GMC and POC tabs; details drawer (flight, reports to, leads, Flip Week position); hover pop-out of supervisors and subordinates; search.

## Photo pipeline
Crop to a 240 x 240 face-centered square (face about 38% of the width), JPEG quality about 82, progressive. Faces come from stored coordinates or OpenCV Haar detection. Patch cutouts must clear every white region touching the image border, not just the corners.
